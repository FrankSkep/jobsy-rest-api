# Backend Jobsy

Este proyecto corresponde al backend de Jobsy, encargado de gestionar la lógica de negocio, la autenticación, la base de datos y la comunicación con el frontend.

## Funcionalidades principales
- Autenticación de usuarios (login, registro, roles).
- Gestión de ofertas de trabajo y postulaciones.
- API para mostrar la ubicación de usuarios y contratantes en el mapa.
- Integración con servicios de geolocalización para mostrar posiciones en tiempo real.
- Seguridad y validación de datos.

## Requisitos
 - Docker para despliegue y desarrollo.
